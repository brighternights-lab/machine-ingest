Account and setup

Everything a new user does in the first ten minutes. Create the account, pair the gateway, bring devices onto the mesh.

Onboarding

Create your account, sign in, reset the password

  1. Open the app, tap Sign Up, enter email and password.
  2. To return, enter credentials and tap Sign In.
  3. Forgot password: tap Forgot Password, open reset link, set a new one.
Rep tip. Walk the homeowner through this once.
Onboarding

Pair a Gateway and update BSP

  1. Unpaired Gateway in range triggers a prompt. Tap ADD then Next.
  2. Name the gateway and confirm with ADD.
  3. Pick Ethernet or WiFi.
  4. If BSP below v59, update runs 8 to 10 minutes.
  5. If BLE below 1B7, tap Update, then Done.
Do not. Switch Wi-Fi networks during firmware.
Onboarding

Create additional networks per site

  1. Top-right icon opens Network overview.
  2. Tap Add, name the network, tap Add.
  3. Rename with the pencil icon. Default Main cannot be deleted.

Change the password after sign-in

  1. More Options then My profile then My Account then Change Password.
  2. Confirm with Yes. Open the reset email.
  3. Enter new password. Tap Submit.
Account

Share account access with other users

  1. Three-line menu then Manage Users then Invite User.
  2. Invite by email or QR code.
  3. Invitee opens My Account, taps Accept Invitations, taps Accept.

Fill out installer and user forms, connect them

  1. Installer side: My Account then Edit Installer Details. Save, Yes.
  2. User side: My Account then Edit User Details.
  3. Once both forms are filled, the user sees the installer's logo in-app.

Dashboard and the UI

UI

New Dashboard tour

  1. Open the app and go to the main Dashboard.
  2. Tap the Menu icon (top left, three lines) to reach Controls, Features, Profile, and Add Device.
  3. Use the Search icon to find a specific device, or the network icon (top right) to switch between networks.
  4. Tap All On or All Off to power every group on the dashboard at once.
  5. Tap the pencil icon on any group to rename it, or the clock icon to add or edit a schedule.
Rep tip. A gateway icon showing a cloud instead of a house means the gateway is on a different network than your phone. If a group reads "Fetching Config..." and stays that way, the gateway may be offline.
UI

Custom color and swatch merge

  1. In any color section, tap the Color + button.
  2. Build the color on the Color Wheel (drag to pick a hue) or with the RGB Sliders (0–255 per channel).
  3. Tap Save to store it in a custom color slot (C1–C12, 12 slots max).
  4. Tap any saved swatch to apply it instantly, or tap Add Swatch to save the color currently showing.
  5. Tap the trash icon on a slot to delete it.
Rep tip. Custom color slots and the swatch list are synced — saving a color to C1–C12 automatically adds it to the swatch list too, so there's no need to save it twice.
UI

Colors, Whites, Light Setting, Effects, Presets

  • Colors. Three-line menu top-left.
  • Whites. White tones at different temperatures.
  • Light Setting. Combined screen.
  • Presets. Pre-built themes.
  • Effects. Up to 4 colors with a speed slider.

Devices and pairing

Device

PWM controller

  1. Tap Pair when prompted, or open the Menu and select Add devices, then drag the PWM device icon into Select group.
  2. Tap the + icon, name the group (e.g. "PWM"), and tap Create.
  3. Tap Add, confirm the PWM type, and tap Done. Use the back arrow (top left) to return to the dashboard.
  4. Control the group with the ON/OFF toggle, All On/All Off, or open More Options (top left) for Colors, Whites, Light setting (RGBW sliders), Presets, and Effects.
  5. To schedule it, go to More Options → Schedules → Add schedule, choose the effect, color/saturation, date range, start time, and weekdays, then tap Create.
Device

Smart Plug

  1. When the app detects an unpaired plug, tap Pair, or open Menu → Add devices and drag the Smart Plug icon into a group.
  2. Tap the + icon to create a new group, name it (e.g. "Smart Plug"), and tap Create.
  3. Tap Add to finish pairing, then tap the back arrow to return to the Dashboard.
  4. Control the plug with the ON/OFF toggle or All On/All Off.
  5. To automate it, go to More Options → Schedules → Add schedule, choose ON or OFF, set the date range (yearly recurrence supported), pick the time and weekdays, then review and tap Create.
Rep tip. Tap the pencil icon on the schedule summary to edit it before saving, or just tap Create to confirm as-is.
Device

Astro Timer

  1. Tap Pair when prompted, or open Menu → Add devices. If it doesn't appear, hold the device's reset button for 10 seconds to force pairing mode, then drag it into Select group.
  2. Tap +, name the group, and tap Create.
  3. Tap Next, then check dawn/dusk times on the Check Timing screen — the app sets these from the install location.
  4. Review the Summary screen and tap Done, then return to the Dashboard.
  5. Go to More Options → Schedules → Add Schedules and choose a type: Dusk (on at dusk), Dawn (on at dawn), or a specific time (off at a set time). Set the ON/OFF option, date range, time offset, and weekdays, then confirm.
Do not. Skip the Check Timing step — dawn/dusk accuracy depends on the location set during pairing.
Device

Exit Sign (life safety)

  1. To reset the unit, press the Reset button five times.
  2. To restore it, open the Installer app, go to Settings → Restore, and follow the on-screen steps.
  3. The unit self-tests automatically — a 30-second test every 30 days and a 90-minute test every 365 days — and reports pass/fail results back over the mesh.
  4. Watch the status LED: green blinking means the self-check passed, red blinking means it failed.
Do not. Ignore a steady red light — it stays on for 24 hours whenever an air quality threshold is exceeded (CO2 ≥1100 ppm, PM2.5 ≥35.5 µg/m³, PM10 ≥255 µg/m³, VOC index ≥300, CO ≥9 ppm, NO2 ≥101 ppm, or temperature/humidity outside 20–26°C / 30–70%) and signals the unit needs service.
Device

40-key BLE Remote

  1. On an unpaired remote, press any key to start advertising so it's discoverable, then open the BNLT firmware tool and select the firmware version to install.
  2. On a remote that's already paired, press and hold key 4 (BRIGHTNESS -) for 5-7 seconds to put it into advertising mode for 15 seconds.
  3. In the BNLT firmware tool, tap Rescue to discover the remote within that window, then run the same update process.
  4. The LED blinks slowly while the update is in progress.
Do not. Wait too long to tap Rescue on a paired remote — the 15-second advertising window closes and you'll need to repeat the key-4 hold to try again.

Groups and virtual groups

Groups

Virtual Groups, the long version

  1. Open the app, tap the Menu icon, and select Virtual Groups.
  2. Tap the Create Group (+) icon, enter a Group Name (e.g. "Outdoor lighting"), select the devices to include, and tap Save.
  3. Control the group with Colors, Whites, Effects, Static Presets, RGBW Sliders, or Schedules, or use the on/off toggle (top right) and the All On/All Off buttons at the bottom.
  4. To change membership, tap Add Device (+) to add devices or open the device list to remove one, then save the change. Tap Sync Virtual Groups to pull in the latest device settings.
  5. To delete a group, tap and hold its name in the group list, select Delete, and confirm.
Do not. Mix an AstroTimer group with anything other than another AstroTimer group of the same type — AC PWM controllers, Smart Plugs, and Streetlights are likewise restricted to their own category. Deleting a Virtual Group does not delete the physical devices in it, and a device can belong to more than one Virtual Group at a time.
Groups

Virtual Groups on the group screen

  1. From the dashboard, scroll past the device list and select Features → Virtual Groups.
  2. Tap the + icon (top right), select the groups to include, assign a name, and tap Save.
  3. Each group tile shows its name, an edit (pencil) icon, the number of linked physical groups, an on/off toggle, and the same controls (Colors, Whites, Effects, Static Presets, RGBW Sliders, Schedules).
  4. Open a group to see its device list with counts and names, add more with the + icon, or use the pencil icon to sync or remove devices.
  5. Use the All Off / All On buttons at the bottom to control every device in the group at once.
Groups

Scenes at group level

  1. Dial in the colors or effects you want using the group's controls.
  2. Tap the group, open More Options (left corner), and select Scenes from the Features list.
  3. Tap the capture icon (top right), then either upload a snapshot image or enter a scene name and tap Save.
  4. The scene appears under the group's Scenes tab with its name — tap Apply to activate it.
  5. To update a scene, dial in the new look, open the scene's edit icon, tap Resave scene, and confirm Yes.
Rep tip. Scenes need addressable pixels in the network — Nuggets, strips, or MR16 bulbs — to capture correctly.
Groups

Automatic scene creation with randomization

  1. Go to More Options → Features → Scenes.
  2. Tap the + icon, then choose Create Scene with Randomizer.
  3. Add colors with the + icon or the AI Suggestions feature.
  4. Set effect intensity (range 0–10, 0 is default), then choose Static or Moving with the toggle.
  5. Tap Apply Randomly, then tap Save Scene.
  6. Upload a snapshot, name the scene, and confirm to save it for future use.
Rep tip. The saved scene keeps whatever settings were randomized, so apply it once to confirm the look before handing the install over.

Apply a new effect

Effects with a base color

  3. Review the movement/change options and switch the ones you want on or off.
  4. Tap Edit colors to adjust effect settings.
  5. To change the main effect color specifically, tap the pen icon.

Effects

Team Colors

  2. Tap Team Colors to open the Team Colors screen.
  3. Browse and select a team from the available options.
  4. Review the team's colors and toggle the effect options you want.
  5. Tap Edit Colors to customize colors and adjust speed.
Do not. Try to use Team Colors on strips that aren't paired in the app yet — the strips must be paired first or the feature won't work.
Effects

Round Robin

  1. Open the side menu, tap Features, then tap Round Robin.
  2. Choose effects from the light effects list (maximum 5 effects).
  3. Tap the + icon to open color selection, pick colors, and confirm with Add (or tap Close top right to skip). Maximum 7 colors. Use AI Suggestions to request specific colors.
  4. Use the + and − icons to set segment length (maximum 10).
  5. Under change style, choose Sequence (effects play one after another) or Random (effects play in random order).
  6. Set the playback duration, from 10 seconds up to 10 minutes.
Effects

Share a custom effect over QR code

  1. Open the side menu, tap Effects, and tap a light from the list.
  2. Tap the + icon, then Create custom effects.
  3. Pick colors and effect settings, then save the effect.
  4. Open the saved effect and tap the share icon (top right) to generate a QR code.
  5. To receive a shared effect, tap Import Effect from QR code, then choose Camera or Gallery to scan or select the code. The effect is added to the custom effects list automatically.
Rep tip. Have the homeowner's light strips already connected in the app before walking them through this — the feature needs an active connection to save to.
Effects

Import, export, share custom colors

  1. For single lights: open More Options → Effects → Normal lights, tap +, then Create custom effect.
  2. For strip lights: go to Effects → Strip lights → Create custom → + → Create custom effect. The color palette offers 64 preset colors plus 12 additional custom colors built with RGBW sliders.
  3. For static presets: go to More Options → Static Presets → Create custom → + → Create custom static preset, and also set segment length and brightness.
  4. In each case, name the effect and tap Create and apply.
  5. To export/share: open the saved effect and tap the share icon (top right) to generate a QR code.
  6. To import: open the matching create screen and tap Import effect from QR code, then scan the code or choose an image from the gallery. Rename or edit the imported effect as needed.
Effects

Home animation in effect preview

  1. Open the Home Animation effect preview.
  2. Use the Adjust Speed slider to set speed (default 110).
  3. Pick a lighting color, using the default or tapping Edit Colors to customize.
  4. Choose an animation effect (examples include Aurora and Bounce).
  5. Use the toggle to turn the effect on or off and review it on the house preview.
  6. Finalize the settings once the preview looks right.
Rep tip. Walk the homeowner through the preview before applying to the real install — it's built to let them try colors, patterns, and animations risk-free first.

Static presets

Preset

Sparkling Diamonds preset

  1. Go to More Options → Static Presets and select Sparkling Diamonds.
  2. Tap Edit colors options, then tap + to open the color palette and choose a preset or custom color.
  3. Set the dimmed segment value, the number of dimmed LEDs following each bright color (range 1 minimum to 10 maximum).
  4. Set brightness to one of: 14%, 28%, 43%, 57%, 71%, 85%, or 100%.
  5. Tap Preview to check the look, then tap Apply to activate.
Rep tip. To schedule it instead of applying now: More Options → Schedules → Lightning → Static Presets → Sparkling Diamonds, set color/segment/brightness, tap Next through to the summary screen, then tap Create. Use Show Preview in device on the summary screen to confirm on-site.
Preset

Static preset with overall brightness

  1. Open Static Presets from the app navigation.
  2. Choose a custom preset or a celebrations/holiday option (e.g. Chinese New Year).
  3. Tap Edit Colors to modify or swap the preset's RGB colors.
  4. Use the + and − buttons to set segment length (range 1 minimum to 10 maximum).
  5. Adjust overall brightness (range 14% minimum to 100% maximum).
  6. Tap Preview to check the look, Apply to commit, or Cancel to discard changes.
Preset

Schedule a static preset

  1. Open the side menu and tap Controls, then Schedules.
  2. Tap Add Schedule, select Lighting, then choose Static Preset.
  3. Pick a theme from Custom, Celebration/Holidays, or Special, then tap Next.
  4. Optional: tap Edit Colors to customize the preset using RGB values or the color wheel, up to 7 colors. Tap Default to restore the original colors.
  5. Set the start and end dates, choose a repeat option (yearly or Repeat Till Year), then tap Next.
  6. Choose a trigger time — Dusk, Dawn, or Specific Time — select the days of the week, then tap Next.
  7. Review the preview and tap Create, then confirm on the pop-up.
Rep tip. Static presets support up to 7 colors per schedule using RGB or the color wheel.

Scheduling

Schedules

New Schedule UI

  1. From the Dashboard, go to Control > Schedule for a network-wide view, or open a device or group to see its own schedules.
  2. Use the top tabs — All, Network, Groups, Virtual Groups, Multi-Groups — to filter which schedules show.
  3. Tap Add Schedule, choose a type (Lighting, Scene, Off, or Spray Controller), then set the active date range and repeat frequency.
  4. Set the start time to a specific time or relative to sunrise or sunset, then assign it to a Device, Group, or Network and save.
  5. For faster setup from a Group, open the Group, tap Schedule, then Add Schedule.
Rep tip. Each schedule card shows its name, date range, active days, and trigger time at a glance — use Select then Delete All to clear out old schedules fast.
Schedules

Schedule a color

  1. From the home screen, tap the menu icon (three lines) in the top-left.
  2. Go to Controls > Schedules, then tap Add Schedule and choose Create a New Schedule.
  3. Select Lighting > Color, then use the color wheel to pick the static color and tap Next.
  4. Set the date range — Selected Range, Every Year, or Repeat Till Year — then tap Next.
  5. Choose Dusk, Dawn, or Specific Time, tap Next, then select the days of the week.
  6. Review the summary and tap Create to save.
Schedules

Schedule an effect

  1. Open the side menu and tap Schedules.
  2. Tap Add Schedule, then Create a New Schedule.
  3. Tap Lighting, select Effects, then pick Normal Light or Strip Light.
  4. Choose a theme, then open the effects screen to adjust speed, colors, and segments, and select the effect you want.
  5. Tap Next, pick the schedule date, and choose a trigger — Dusk, Dawn, or Specific Time.
  6. Review the summary screen and tap Create.
Rep tip. The selected theme and effect run automatically at the scheduled time — no need to trigger it manually later.
Schedules

Schedule a light setting

  1. Open the app, select Schedules from the navigation menu, then tap Create a New Schedule.
  2. Choose Light Setting and set brightness and color using the Red, Green, Blue, White, and Brightness sliders (for example, RGB 0, 255, 0 with 100% brightness for bright green). Use Preview or saved swatches to confirm.
  3. Select the target Groups and Ports (1–4).
  4. Set the Start Date and End Date using Selected Range, Every Year, or Repeat Till Year.
  5. Choose Dusk, Dawn, or Specific Time, adding an offset if needed (up to +3h), then check the days of the week to repeat on.
  6. Tap Show Preview On Device to test, then tap Create to finalize.
Do not. Time offsets cap at +3 hours — don't try to schedule further out than that from Dusk or Dawn.
Schedules

Holiday scheduling

  1. Open the side menu, tap the Features icon, then select Holiday Scheduling.
  2. Choose a holiday from the list of predefined lighting themes (Halloween, Christmas, New Year, etc.) and tap Continue. Up to 5 schedules can be selected at once.
  3. Pick the lighting groups to apply it to, or tap Continue with all your lights to apply it everywhere.
  4. Tap Edit Schedule to adjust timing, date, name, range, days, or effects (groups can't be changed at this step).
  5. Tap Preview On Device to confirm before saving.
  6. Tap Save for one schedule or Save All Schedules for multiple, then confirm on the pop-up.
Do not. Selecting more than 5 holiday schedules triggers a limit warning, and mixing normal groups with virtual groups in one selection isn't allowed.
Schedules

DST handling, firmware side

  1. Check the controller's firmware version before relying on automatic DST handling — older firmware needs the time adjusted manually in the app instead.
  2. Minimum firmware for automatic DST support: Strip Controller 0x1DE, PWM 0x1C1, Analog 0x1CA, Astro Timer 0x1C4, Spray Controller 0x1A4, Smart Plug 0x1B2, Wallwasher 0x1B9.
  3. On supported firmware, the controller shifts scheduled times by plus or minus one hour automatically at the spring/fall transition — no app action needed.
  4. On unsupported firmware, run Sync Current Time from the app after the DST change so schedules stay aligned.
Rep tip. If a customer's schedules are off by an hour right after a time change, it's almost always a firmware version below the thresholds above — update the firmware or have them sync manually.
Schedules

DST, Sync Time, user-facing

  1. Open the app and go to the Side Menu.
  2. Tap Settings.
  3. Select Sync Current Time.
  4. Wait for the light to blink, confirming the time synced successfully.
Do not. Avoid scheduling anything between 1:00–3:00 AM. Spring-forward schedules in the 2:00–3:00 AM window can get skipped for a day, and fall-back schedules in the 1:00–2:00 AM window can run twice. Use a time like 12:55 AM or 2:05 AM instead, and run Sync Current Time after each DST change.

Security

Security Lighting with two colors

House design and AI

Design

Pick and Decorate your house

  1. Tap the Capture icon to take a photo of the house or upload one from your gallery.
  2. Tap Draw Next Path and trace a dotted line across the area you want to light — the dots set the direction and flow of the effect.
  3. Pick a light type for that path: MR16 Light, Wall Washer Light, or Normal Strip Light.

Rep tip. Save the preview often while you work — tapping the Capture icon again replaces the current photo and any work since the last save is lost.
AI

AI assistant inside the app

  1. Open the app and pair your outdoor lighting devices when prompted.
  2. Open the side menu and select the AI assistant.
  3. Use Support to look up device details, troubleshoot, check for firmware updates, or walk through pairing and reset steps.
  4. Use Set Lights to apply colors, static presets, or effects, turn on security lighting, or save and activate a scene.

Installer tools and firmware

Installer

Installer tools menu

  1. Tap the menu icon (three lines, top left), scroll down, and select Settings, then tap Next on the notification.
  2. Use Repair GW Tunnel to fix remote gateway access in Socket Mode — connect to the same Wi-Fi as the gateway, wait for the house icon to appear, then select it.
  3. Use Check Clock to confirm device timing: a white blink means it's working, a red blink means it's not; for astro timers, two blinks is working and three is not.
  4. Use Check Server Details to view the groups and devices tied to the server, or Email Sync Issue to send a sync problem to support.
  5. Use Delete All Schedules to clear schedules from the devices, gateway, and server, then confirm Yes — you'll still need to delete them from the app separately.
  6. Use Reset Deleted Devices for devices that were deleted but never reset, and Restore Devices (requires an active gateway connection) to bring reset devices back.
Do not. Log out while a "Pending Changes" notification is showing — run Sync to Server first or those changes are lost.
Firmware

Firmware update, Gateway path

  1. Tap the menu icon (three lines, top left), select Features, then Firmware Updates, and tap Next on the notification.
  2. Choose Update device using Gateway and tap Next on the confirmation pop-up.
  3. The app scans for devices on the gateway and lists them — select the devices to update and tap Next to confirm.
  4. The update runs for about 8–10 minutes. When the Wait pop-up appears, tap OK and let it finish.
Do not. Start this with a weak internet connection or outside Socket/SQS mode — both are required for the gateway update to complete.
Firmware

Firmware update, installer app path

  1. In the BNLT firmware tool, tap the menu icon (three lines, top left), scroll down, and select Firmware Updates, then tap Next on the notification.
  2. Find the device on the list and tap Update next to it, then hold your phone as close as possible to that device.
  3. Wait 2–3 minutes for the update to finish and for the success notification.
  4. Watch the device's LED — it pulses through colors during the update and returns to its normal color when the install is complete.
Do not. Turn off power to the device while its firmware update is running, or update more than one device at a time — disable other nearby devices first and keep your phone plugged in and close to the target device.

Alerts, integrations, marketing assets

Alerts

Misting warning at network level

  1. Make sure the gateway is online — spray controller alerts and control only work with network connectivity.
  2. When chemical in the tank drops to 10 inches remaining, a Spray Controller warning Alert appears with a yellow border: "Your spray controller is almost out of chemical. Please refill it soon."
  3. When the level drops to 5 inches, the alert escalates to a Spray Controller Empty Alert with a red border.
  4. Refill the chemical tank to clear the alert.
Do not. Wait on a yellow-border warning — by the time the red Empty Alert appears the tank is already out of chemical.
Integrations

IFTTT integration

  1. Tap the menu (top left), select More Options, then Integrations, and tap Show Connections.
  2. If not yet connected, follow the link to connect your account through Safari or the IFTTT app using the same login as the main app.
  3. Pick a connection (for example, a location-based lighting sync), slide the Connect button at the bottom, then tap Configure in IFTTT and turn the switch on.
  4. In the first field, set the area to locate; in the second, choose which lights to turn on for that location.
  5. To build a custom Applet instead: in IFTTT tap your profile picture, Create, + This to pick a trigger, + That to pick the lighting action, then activate and test it.
Rep tip. You need at least one smart lighting device and one gateway device connected before IFTTT will work, and always run the test trigger after activating a new Applet to confirm it fires.
Marketing

Auto-Download of marketing assets

  2. Toggle the switch on, then go to Marketing Asset and tap the Downloads icon in the top right to see everything that's been pulled down automatically.
  3. From the list, tap an asset to View, Share, or Delete it, or tap Cancel to close the popup.
  4. To turn it off, toggle the switch off and confirm Yes when prompted.
Do not. Turn off Auto-Download Assets expecting to keep what's already downloaded — doing so deletes every previously downloaded asset, and new ones then have to be pulled one at a time from Marketing Assets.
Marketing

Automatic co-branded assets

  1. Open the menu (three lines, top left), go to My Profile → My Account → Edit Installer Details, and fill in the form.
  2. Allow up to 24 hours for your details to sync into the auto-download assets.
  3. Open the menu → Resources → Marketing Assets, then select Marketing Assets with your Branding.
  4. Choose Brochure, Social Media Post, or Trifold — each is automatically branded with your logo and details.
  5. Tap Download or Share on the finished PDF.
Rep tip. Assets won't reflect your branding until the 24-hour sync finishes, so update your installer details well before you need the materials.

Troubleshooting index

Fast fixes grouped by category.

Account and sign-in

Forgot password, reset link not arriving.

Fix. Check spam. Confirm registered email. Re-trigger from the Forgot Password screen.

Sign-in fails after a password change.

Fix. Logout, close, reopen, sign in with new credentials.

Gateway and network

Gateway pairing stuck during BSP update.

Fix. Do not switch Wi-Fi during firmware. Wait 8-10 minutes.

Gateway offline (cloud icon only).

Fix. Check Wi-Fi. Verify Ethernet. Power-cycle gateway.

Gateway icon shows a cloud instead of a house, or a group is stuck on "Fetching Config...".

Fix. A cloud icon means the gateway is on a different network than your phone. A group stuck on Fetching Config usually means the gateway is offline — check its Wi-Fi/Ethernet connection and power.

Devices and pairing

PWM controller will not pair.

Fix. Confirm Main network. Hold reset. Pick correct PWM type.

Astro Timer schedules fire at the wrong time.

Fix. Reconfirm install address. Re-run Check Timing.

40-key remote not responding.

Fix. Press any key to wake. Hold keys 1 and 2 together 10 seconds to clear pair.

Schedules and DST

Schedule skipped on DST day.

Fix. Move critical events to 12:55am or 2:05am.

Holiday scheduling save fails.

Fix. Devices must stay connected while building the schedule.

Schedule won't trigger more than a few hours from Dusk/Dawn.

Fix. Time offsets are capped at +3 hours from Dusk or Dawn. Schedule further out with a Specific Time entry instead.

Holiday schedule won't save, or normal and virtual groups won't combine.

Fix. Holiday Scheduling caps at 5 schedules selected at once, and normal groups can't be mixed with virtual groups in the same selection.

Customer's schedules run an hour off right after a time change.

Fix. Almost always a firmware version below the DST-support threshold — update the firmware, or have the customer run Sync Current Time manually.

Groups and virtual groups

Virtual Group mixes device types that don't belong together.

Fix. Keep AstroTimer, AC PWM, Smart Plug, and Streetlight devices in groups of their own type only — don't mix categories in one Virtual Group.

Physical devices seem to disappear after deleting a Virtual Group.

Fix. Deleting a Virtual Group never deletes the physical devices in it. If devices are missing, check whether they were also removed from their original group.

Scene capture doesn't produce a usable preview.

Fix. Scenes need addressable pixels — Nuggets, strips, or MR16 bulbs — in the network to capture correctly. Non-addressable devices can't be captured into a scene.

Effects

Edit Colors doesn't change the effect's base color.

Fix. Edit Colors adjusts the secondary effect settings only. Tap the pen icon to change the main/base color specifically.

Team Colors effect won't apply to a strip.

Fix. The strip must be paired in the app first — Team Colors can't target an unpaired strip.

Security lighting

Save and Apply is disabled on a security lighting port.

Fix. At least one light must be selected for the second color before Save and Apply will work. Use clear all to reset a port's selections if needed.

Security lighting schedule has nothing to run.

Fix. Select and save lights for the port's security lighting setup first — a scene can't be built from an empty selection.

House design and AI

House design preview photo and unsaved work are gone.

Fix. Save the preview often while you work. Tapping the Capture icon again replaces the current photo and discards any work since the last save.

Installer tools and firmware

Changes are lost after logging out.

Fix. Don't log out while a "Pending Changes" notification is showing — run Sync to Server first.

Gateway firmware update stalls or fails to complete.

Fix. Confirm a strong internet connection and that the gateway is in Socket/SQS mode before starting — both are required for the update to finish.

Firmware update on the BNLT firmware tool fails mid-update.

Fix. Don't power off the device mid-update, and update only one device at a time. Disable other nearby devices and keep your phone plugged in and close to the target device.

Alerts, integrations, marketing

Spray controller chemical ran out before a refill happened.

Fix. Don't wait on the yellow-border warning — refill as soon as it appears. By the time the red Empty Alert shows, the tank is already out.

Auto-Download Assets turned off and previously downloaded files are gone.

Fix. Turning off Auto-Download Assets deletes every previously downloaded asset. Save anything you need elsewhere before disabling it.

IFTTT Applet doesn't fire.

Fix. Confirm at least one smart lighting device and one gateway device are connected, then run the test trigger after activating any new Applet.

Co-branded marketing assets still show old or no installer branding.

Fix. Allow up to 24 hours after updating Installer Details for the auto-download assets to sync before expecting new branding.
