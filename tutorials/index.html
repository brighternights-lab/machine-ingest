Account and setup

Everything a new user does in the first ten minutes. Create the account, pair the gateway, bring devices onto the mesh.

Onboarding

Create your account, sign in, reset the password

  1. Open the app, tap Sign Up, enter email and password. Account unlocks cloud backup for settings.
  2. To return to a device, enter credentials and tap Sign In. The network list opens.
  3. Forgot password: tap Forgot Password, enter the registered email, open the reset link, set a new one.
Rep tip. Walk the homeowner through this once. The account acts like a Wi-Fi password for the mesh network.
Onboarding

Pair a Gateway and update BSP

  1. Unpaired Gateway in range triggers a prompt on the Network screen. Tap ADD then Next.
  2. Name the gateway and confirm with ADD.
  3. Pick Ethernet or WiFi. For Wi-Fi, phone and gateway on the same network.
  4. If BSP is below v59, the update popup runs 8 to 10 minutes.
  5. If BLE version is below 1B7, tap Update, let it run, then Done.
Do not. Switch Wi-Fi networks on the phone during firmware. The handshake breaks and the gateway re-enters pairing.
Onboarding

Create additional networks per site

  1. Top-right icon on the main screen opens Network overview.
  2. Tap Add, name the new network, tap Add.
  3. Rename with the pencil icon. The default Main can be renamed but never deleted.

One device belongs to one network at a time. Multi-building sites, each location gets its own network.

Account

Change the password after sign-in

  1. More Options then My profile then My Account then Change Password.
  2. Confirm with Yes. Open the reset email and tap Click here to proceed.
  3. Enter and confirm the new password. Tap Submit.
  4. Back in the app, tap Logout and sign in with the new credentials.
Account

Share account access with other users

  1. Three-line menu then My Account then Manage Users then Invite User.
  2. Two ways to invite: by email (type name, pick network, Send) or by QR code.
  3. Invitee creates/signs into their account, opens My Account, taps Accept Invitations, taps Accept on the row.
  4. After acceptance, both users switch between networks using the toggle on the Account page.
Limit. A second user cannot drive a device while the primary user is actively connected to it.
Branding

Fill out installer and user forms, connect them

  1. Installer side. Pro app: My Account then Edit Installer Details. Company name, logo, address. Save then Yes.
  2. User side. Homeowner app: My Account then Edit User Details. Fill all fields and save.
  3. Once both forms are filled, the user sees the installer's logo in-app and can reach the installer directly.
Why it matters. These forms match homeowners to the correct certified installer.

Dashboard and the UI

What opens after sign-in and the one-tool merge for colors and swatches.

UI

New Dashboard tour

Everything the app can do sits here. Gateway, music, groups, virtual groups, all in one scrollable view.

  • Gateway Control. Status icons show same network, different network, Bluetooth presence.
  • Music Integration. Linked audio device status with MAC and firmware details on tap.
  • Spray Controller. Toggle, schedule, and group misting devices.
  • Virtual Groups. Each tile shows group name, linked physical group count, on/off toggle.
  • Global Controls. All On and All Off at the bottom hit every device at once.
UI

Custom color and swatch merge

Custom colors and the swatch bar are now one tool. Build colors on the wheel or with RGB sliders. Up to C12 slots.

  1. Drag the circle on the wheel, or move RGB sliders 0 to 255.
  2. Saving to a slot through C12 drops that color onto the swatch list automatically.
  3. Trash icon to delete, or tap filled slot and Save to overwrite.

Where it shows up. Effects. Static Presets. Security Lighting. Any screen that asks for a color.

UI

Colors, Whites, Light Setting, Effects, Presets

  • Colors. Three-line menu top-left. Color, brightness, saturation. Add Swatch saves. Hold a swatch about one second to delete.
  • Whites. Same menu. White tones at different color temperatures. Brightness arrows.
  • Light Setting. Combined screen. Swipe to set color and brightness in one gesture.
  • Presets. Pre-built themes from the main menu.
  • Effects. Normal effects support up to 4 colors with a speed slider. Strip effects support up to 8.

Preview before you commit. Effect Preview button runs the pattern before it hits the lights outside.

Devices and pairing

Every device type, how it pairs, how it schedules, what controls it supports.

Device

PWM controller

  1. From the Main network, tap Pair on the popup. No popup, three lines then Add devices.
  2. Drag the PWM icon into Select group. Tap Create, name the group, tap.
  3. Tap Add. Pick PWM type on Choose PWM type. Tap Done.

Controls. ON/OFF toggle. All On, All Off. More Options exposes Colors, Whites, RGBW sliders, Presets, Effects.

Device

Smart Plug

  1. Pair the same way. Popup, Pair. Or three-line menu, Add devices. Drag the Smart Plug icon.
  2. Create or pick a group. Tap Add.

Create an ON automation. Schedules then Add Schedule. Date range or whole year, choose turn-on time. Days of the week. Summary. Create.

What it drives. Plug-and-play Bluetooth single or four-channel controller for permanent nugget roofline, 3-wire C9, and more.

Device

Astro Timer

  1. Pair. If no popup, hold reset button on the side 10 seconds.
  2. Drag the Astro Timer icon into Select group. Create group. Next.
  3. Check Timing. Confirm dusk/dawn offsets match the install address. Next.
  4. Summary. All three steps complete. Done.
Device

Device

40-key BLE Remote

Press any key to wake. Remote opens a 15 second advertising window. Connect from the Pro app inside that window.

  • Reset. Hold keys 1 and 2 together roughly 10 seconds. LED blinks rapidly when the pair clears.
  • Firmware (unpaired). Press any key, pick firmware version in the Pro app.
  • Firmware (paired). Hold key 4 (BRIGHTNESS -) 5 to 7 seconds, then tap Rescue in the app.

Groups and virtual groups

Virtual Groups bundle other groups. Treat as one unit for control.

Groups

Virtual Groups, the long version

A Virtual Group is a software bundle of other groups. Treat it as one unit for color, white, effect, preset, slider, and schedule control.

Create.

  1. Tap Create Group (+).
  2. Name the group. Living Room. Office. Outdoor lighting.
  3. Select devices. Tap Save.
Rules. AstroTimer groups only combine with other AstroTimer groups of the same type. Same for AC PWM, Smart Plugs, Streetlights.
Groups

Virtual Groups on the group screen

Dashboard then Features then Virtual Groups. Each tile shows name, edit control, linked physical group count, All Off / All On.

Groups

Scenes at group level

  1. Apply colors or effects from the side menu at the group as normal.
  2. Group More Options then Scenes.
  3. Capture icon top right. Upload snapshot, name the scene, save.
Groups

Automatic scene creation with randomization

  1. More Options then Features then Scenes.
  2. Tap then Create Scene with Randomizer.
  3. Add colors or use AI suggestions.
  4. Effect segments 0 (default) to 10 (max).
  5. Toggle Static or Moving.
  6. Tap Apply Randomly, then Save Scene.

Apply a new effect

Effects

Effects with a base color

Effects that lock to a chosen base color. Available on strip lights with the strip paired.

  • Bounce, Bouncing ball, Fuse, Multispot light, Stack, Thunderstorm.

Edit Colors preserves the main color. To change the primary color itself, tap the pen icon.

Effects

Team Colors

Pre-set colors for a team's brand. Strips must be paired first.

  1. Side menu then Effects.
  2. Strip Lights then Team Colors.
  3. Pick a team. Toggle any of the team-tagged effects below.
Effects

Round Robin, multiple effects in sequence

Side menu then RoundRobin. Up to 5 effects in a cycle. Up to 7 colors per effect. Timing per step 10 seconds to 10 minutes.

Effects

Share a custom effect over QR code

  1. Side menu then Effects. Pick the light.
  2. Tap Create custom effects. Set colors and effects. Save.
  3. Share icon top right. A QR code appears.
  4. Peers import under Import Effect from QR code via camera or gallery.
Effects

Import, export, share custom colors

Normal lights. More Options then Effects then Normal lights. Tap, name, pick colors, Save. Share button exports a QR.

Strip lights. Same flow with a palette of 64 colors plus 12 custom slots.

Effects

Home animation in effect preview

  • Speed slider sets the pace.
  • Colors. Keep defaults or tap Edit Colors.
  • Select Effect. Aurora, Bounce, and the rest toggle on and off.
  • Preview. Watch the pattern before pushing it to the install.

Schedule a light setting

Holiday scheduling

  4. Preview. Save All Schedules.

Schedules

DST handling, firmware side

How the app ships schedules into the gateway and firmware across time changes.

  • Sync Current Time. Unix time plus an is_dst flag.
  • Set Schedules. Start times carry the current date.
  • Verify Schedule. Unix time comes back as-is.

Schedules

DST, Sync Time, and the user-facing side

Side Menu then Settings then Sync Current Time. The device blinks to confirm.

  • March. A schedule between 2:00 and 3:00 am may be skipped for one day.
  • November. A schedule at 1:00 to 2:00 am may run twice for one day.
Rule of thumb. Do not schedule critical events exactly at 1:00 am or 2:00 am. 12:55 am or 2:05 am is safer.

Troubleshooting index

Fast fixes grouped by category. Open the matching tutorial for the full flow.

Account and sign-in

Forgot password, reset link not arriving.

Fix. Check spam. Confirm the exact registered email. Re-trigger from the Forgot Password screen.

Sign-in fails after a password change.

Fix. Logout, close the app, reopen, sign in with the new credentials. Old sessions do not refresh automatically.

Secondary user cannot drive a device.

Fix. Primary user must disconnect first.

Gateway and network

Gateway pairing stuck during BSP update.

Fix. Do not switch Wi-Fi networks on the phone during the firmware step. Wait the full 8 to 10 minutes.

Gateway offline (cloud icon only).

Fix. Check the installer location Wi-Fi. Verify Ethernet if used. Power-cycle the gateway.

No pairing popup appears.

Fix. Three-line menu then Add devices. Hold the reset button on the device for 10 seconds.

Devices and pairing

PWM controller will not pair.

Fix. Confirm you are on the Main network. Hold reset. Re-trigger via Add devices. Pick the correct PWM type.

Astro Timer schedules fire at the wrong time.

Fix. Reconfirm the install address. Dusk/dawn offsets rely on it.

Smart Plug schedule does not run.

Fix. Confirm the plug is paired to the correct group. Confirm the days-of-week picker. Re-save the schedule.

40-key remote not responding.

Fix. Press any key to wake. 15-second advertising window. If stuck, hold keys 1 and 2 together 10 seconds.

Firmware updates

Firmware update failed partway.

Fix. Keep the phone on the same Wi-Fi. Retry from the installer firmware tool.

Device below minimum firmware for autonomous DST.

Fix. Update to the minimum version in the DST firmware table.

Virtual Groups

Can't add device to a Virtual Group.

Fix. Category mix rule. AstroTimer only combines with AstroTimer. Same for AC PWM, Smart Plugs, Streetlights.

Group out of sync with underlying devices.

Fix. Open the group, tap Sync Virtual Groups.

Scenes, effects, presets

Scene changes don't persist.

Fix. Apply colors or effects first, then resave the scene using the edit icon.

Base-color effect missing from list.

Fix. Base-color effects require a paired strip.

QR code import fails.

Fix. Use Import Effect from QR code screen. Try scanning from gallery instead of live camera.

Security lighting

Second color not applying.

Fix. Confirm the port supports dual-color. Only roof-line and strip channels on 2-channel and 4-channel controllers.

Schedules and DST

Schedule skipped on DST day.

Fix. Schedules between 2-3am (March) or 1-2am (November) are affected. Move critical events to 12:55am or 2:05am.

Holiday scheduling save fails.

Fix. Devices must stay connected while the schedule is being built. Reconnect and rebuild.

Mixed normal + virtual group schedule rejected.

Fix. Normal groups and virtual groups cannot mix in one Holiday schedule. Create two schedules.

Alerts and integrations

Misting warning banner won't clear.

Fix. Resolve the condition the banner names.

IFTTT applet not triggering.

Fix. Re-authorize the IFTTT connection. Confirm applet mapping to a valid scene/group/preset.

Marketing assets

Co-branded brochures missing installer logo.

Fix. Fill the Edit Installer Details form (logo, address, name, phone, email).

Auto-download assets not refreshing.

Fix. Confirm the Auto Download toggle. Pull-to-refresh the Marketing Assets screen.

Air quality (Exit Sign) alerts

Air quality alert fires repeatedly.

Fix. Confirm thresholds. CO2 >=1100 ppm, PM2.5 >=35.5 ug/m3, temperature outside 20-26C, humidity outside 30-70%.

Rebrand ruleset applied

  • Installer / contractor / pro references → BNLT branding.
  • Firmware tool → BNLT firmware tool.
  • MeshTek kept in technical references; swapped for BNLT names in product-facing content.
  • Competitor's homeowner app name used only when the content specifically describes the competitor.

Design system in use

  • Gradient: #00A9B5 → #5BE3DD → #EC008C → #E3056B → #FF7A1A.
  • All pills / buttons / callouts: ghost style (transparent background, colored border, colored text).
  • Dark ground #0B0E18; card #111726; ink #EAF2F8; muted #9FB4C7.
  • Tab switch scrolls to top (standing UX rule).
