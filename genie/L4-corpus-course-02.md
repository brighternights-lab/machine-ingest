# Module 3 Lesson 3.1 — System Specs & Structural Differences Pool Enclosure System Components The pool enclosure lighting system consists of: P

**Module.** Pool enclosure track lighting system (plug and play)
**Topic.** Pool enclosure track lighting system
**Audience.** Certified contractor (L4) and Certified distributor rep (L5)

Lesson 3.1: System Specs & Structural Differences Pool Enclosure System Components The pool enclosure lighting system consists of: Pool enclosure track (10.5 ft receiver channel) Power supply (200W) 1 - port controller (Bluetooth) Signal amplifiers Lead lines Light strands System Overview The pool enclosure system uses a 10.5 - foot laser - cut aluminum receiver channel, which is completely different from the roofline system. This track is made from the exact same aluminum used in pool enclosures, with the same powder coating, and comes from the same factories. That means: True color match to the enclosure Seamless integration into the structure Built for the same environmental conditions Available colors: Black Bronze White Key Difference from Roofline System Pool enclosure track: 10.5 ft sections Same aluminum as enclosure Same powder coating Structural match Roofline track: 3 ft sections Thinner gauge aluminum Designed for fascia mounting These are two completely different systems designed for different applications. Why This Matters Pool enclosures deal with: Humidity Chlorine exposure Coastal environments Because the track matches the enclosure material: It resists corrosion Expands and contracts consistently Maintains a clean, uniform look Will not fade any faster than the enclosure itself This system was designed to match the lifespan and performance of the enclosure. Self - Mating Beams & Screw Elimination In pool enclosures, the overhead beams are called self - mating beams. These beams typically have: Screws facing downward Spaced every 12 – 16 inches Visible from inside the enclosure When our track is installed: It replaces and covers those screws Eliminates visible screw heads Reduces exposure to moisture Slows rust and corrosion Creates a cleaner finished look By covering these screws, the system: Increases enclosure longevity Reduces visible wear over time This system doesn't just add lighting — it improves the enclosure itself.

# Module 3 Lesson 3.3 — Wire Routing & Controller Setup System Flow Power Supply →

**Module.** Pool enclosure track lighting system (plug and play)
**Topic.** Pool enclosure track lighting system
**Audience.** Certified contractor (L4) and Certified distributor rep (L5)

Lesson 3.3: Wire Routing & Controller Setup System Flow Power Supply → 1 - Port Controller → Lead Lines (with signal amplifiers placed as needed) → Lights Controller Setup Uses a 1 - port Bluetooth controller Installed inside a sealed waterproof enclosure box Mounting: Secure to enclosure structure Keep accessible for service Protect from direct exposure when possible Wire Routing Run lead lines along self - mating beams Keep tight to structure Follow beam lines for concealment Goal: clean, hidden wiring that blends into the enclosure. Signal Amplifier Placement & Testing Placement Signal amplifiers are used across all systems. Place them approximately: Every 5 – 10 feet of lead line What Affects Placement Number of jumps Length of lead lines System size Layout complexity The more jumps and distance, the more signal support is required. Why This Matters Signal drops across lead lines. If not corrected: Lights may flicker Colors may not transition properly Sections may behave inconsistently How to Test After installation: Run through color changes Focus on warm white to cool white transitions Cool white draws the most power and will expose issues first. What to Look For Flickering lights Uneven brightness Poor color transitions How to Fix If flickering occurs: Add a signal amplifier Place it before the problem area Re - test the system Installer Rule Always test the system before finishing the job. If there is flickering, more signal support is needed. Close It is always easier to add a signal amplifier during installation than return for a service call later. # Module 4 Lesson 4.1 — System Specs & Mounting System Overview The soffit lighting system uses individual soffit light fixtures, not light stra

**Module.** Soffit lighting system (plug and play)
**Topic.** Soffit lighting system
**Audience.** Certified contractor (L4) and Certified distributor rep (L5)

Lesson 4.1: System Specs & Mounting System Overview The soffit lighting system uses individual soffit light fixtures, not light strands in a track. Available kits: 4 - pack 8 - pack 12 - pack Fixture Design The soffit lighting system is a two - piece fixture design: Soffit light (approximately 4 inches in diameter) Shroud (cover) The shroud is what gets mounted to the soffit and is where the screws are installed. Shroud cover colors: Black White Bronze There are: No brackets No recessed cans Key Advantage No recessed cans required No large holes required Faster installs Less damage to the home Easier serviceability Power Requirements (IMPORTANT) Each soffit light uses approximately 12 watts per fixture. With a 200W power supply: You should plan for approximately 12 lights per power supply Installer Rule Every ~12 soffit lights should have its own dedicated power supply This ensures: Proper performance No overload Long - term reliability Layout & Spacing There is no fixed spacing rule. Recommended approach: Focus on symmetry across the property Align lights with: Columns Architectural features Entry points Typical spacing: Approximately 8 to 16 feet, depending on: Roofline layout Property size Use good judgment — layout is critical for visual appeal. Mounting the Fixture Mount using screws through the shroud directly into the soffit Ensure fixtures are aligned and evenly spaced Competitive Positioning vs Recessed Lighting (IMPORTANT) Traditional soffit lighting uses recessed can lighting, which: Requires cutting holes for can fixtures Is more labor - intensive and expensive Typically only offers a single color (no RGB control) Has no addressability Does not include built - in scheduling or timer functionality Brighter Nights Advantage Our soffit lighting system: Is flush - mounted for a clean, modern look Does not require cutting out a can Requires only a small hole for wiring Offers full color - changing capability Allows individual addressability (up to 20 lights) Includes built - in timers and scheduling features through the controller Every system with a controller can be scheduled and automated. Close This allows contractors to offer a more advanced, lower - cost, and higher - value solution compared to traditional recessed lighting.
