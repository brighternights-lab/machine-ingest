# Module 2 Lesson 2.1 — System Specs and Sizing

**Module.** Roofline track lighting system (plug and play)
**Topic.** Roofline track lighting system
**Audience.** Certified contractor (L4) and Certified distributor rep (L5)

System Specs. 24V system. 200W power supply. IP67 rated. 30mm HD diodes. 12 inch spacing.

Track Colors. Black. White. Bronze.

Wire matching. Black track → black wire. Bronze track → black wire. White track → white wire. Bronze track is designed to match dark brown soffits and pool enclosures.

Accessories Colors. Lead lines, T connectors, and signal amplifiers are available in Black and White.

Kit Sizes. 100 ft. 150 ft. 200 ft. 300 ft.

Power Planning. Each light uses approximately 0.55 watts per light. Only use about 85% of total power supply capacity. 200W power supply gives 170W usable. Real world capacity is approximately 309 lights max. Safe range is 290 to 300 lights. Never design to max capacity, always leave buffer.

Measuring a Roofline. 1. Start at power supply location. 2. Measure each fascia run. 3. Include corners, peaks, returns. 4. Add total footage. 5. Add 10 to 15% extra. 6. Round up to next kit size.

# Module 2 Lesson 2.2 — Metal Fabrication

**Module.** Roofline track lighting system (plug and play)
**Topic.** Roofline track lighting system
**Audience.** Certified contractor (L4) and Certified distributor rep (L5)

Step 1 Marking. Use a marker and speed square to mark clean cut lines.

Step 2 Cutting. Use miter saw (preferred), angle grinder, or metal snips.

Step 3 Angles. Inside corner 45°. Outside corner 45° opposite direction. Gable two 45° cuts forming a peak. Note not all cuts will be perfect 45° depending on roof pitch, 45° is the most common baseline.

Step 4 Deburring. Smooth edges using a file or grinder to prevent wire damage and ensure proper fit.

Step 5 Joining. Align pieces tightly before fastening.

Step 6 Fastening. Use self tapping screws or sheet metal screws.

Prefab Corners. Save time. Improve consistency. Reduce install errors.

# Module 2 Lesson 2.3 — Track Mounting and Wire Hiding

**Module.** Roofline track lighting system (plug and play)
**Topic.** Roofline track lighting system
**Audience.** Certified contractor (L4) and Certified distributor rep (L5)

Mounting. Mount directly to fascia. Surface must be clean, dry, and structurally sound.

Fastener Spacing. Typically every 12 to 24 inches depending on conditions.

Wire Hiding. Run along seams. Tuck behind fascia and soffit. Use clips or channels for wire management. Goal is no visible wires from ground level.

# Module 2 Lesson 2.4 — Wiring Sequence and System Limits

**Module.** Roofline track lighting system (plug and play)
**Topic.** Roofline track lighting system
**Audience.** Certified contractor (L4) and Certified distributor rep (L5)

Connection Sequence. 1. Power supply to controller. 2. Controller to first track section. 3. Track to track via waterproof plugs. 4. Signal amplifiers after every 300 lights or long runs. 5. T connectors for branches off the main run. 6. End caps on terminal runs.

System Limits. Max 309 lights per 200W power supply (safe range 290 to 300). Max 300 lights downstream of a single signal amplifier. Max run length per segment approximately 100 feet before signal amplifier recommended. Always route around sharp metal edges and sources of standing water.

Testing. Power on in sequence. Check each run segment with the Pro app. Verify color and brightness commands reach the end of each run. If the last 10% of a run is dim or non responsive, drop in a signal amplifier upstream of that segment.
