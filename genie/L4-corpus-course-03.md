**Module.** Soffit lighting system (plug and play)
**Topic.** Soffit lighting system
**Audience.** Certified contractor (L4) and Certified distributor rep (L5)

Lesson 4.3: Wiring Sequence & System Setup System Components The soffit system uses the same core components as the roofline and deck lighting systems: Power supply (200W) 1 - port controller Signal amplifiers Lead lines (1ft, 3ft, 5ft, 10ft) Individual soffit lights Connection Flow Power Supply → 1 - Port Controller → Signal Amplifiers (as needed) → Lead Lines → Lights Signal Amplifier Placement Place approximately every 5 – 10 feet of lead line Placement depends on: Number of jumps Distance between fixtures Layout complexity Addressable Lighting Feature Each soffit light can be individually controlled and programmed. Up to 20 lights are individually addressable Each light can have its own color After 20 lights, the pattern repeats Testing the System After installation: Run through full color range Focus on warm white to cool white transitions What to Look For Flickering lights Uneven brightness Poor color transitions Cool white draws the most power and will expose issues first. How to Fix Issues If flickering occurs: Add a signal amplifier Place it before the problem area Re - test the system Installer Rule Always test the system before completing the job. If there is flickering, additional signal support is required. Close Clean layout, proper spacing, correct signal placement, and proper power planning ensure a professional installation with no callbacks. Using the same components across multiple systems makes installation more consistent, easier to learn, and easier to scale as a contractor. # Module 6 Lesson 6.1 — System Specs & Transformer Loads System Overview The sconce lighting system is part of the low - voltage wiring (LVW) sy

**Module.** Sconce lighting system (LVW)
**Topic.** Sconce lighting system (LVW)
**Audience.** Certified contractor (L4) and Certified distributor rep (L5)

Lesson 6.1: System Specs & Transformer Loads System Overview The sconce lighting system is part of the low - voltage wiring (LVW) system, which is different from plug - and - play systems. This system requires splicing, which is standard across the landscape lighting industry. Fixture Types There are two types of sconces: Full Sconce: Uses 2 MR16 bulbs (up and down lighting) Total: ~11 watts per fixture (5.5W per bulb) Half Sconce: Uses 1 MR16 bulb Total: ~5.5 watts per fixture Bulb Technology (IMPORTANT) Each MR16 bulb: Has a built - in Bluetooth antenna Is individually addressable Can display: Different colors Static patterns Moving patterns Top and bottom bulbs on a full sconce can each have independent control HyperLux Technology (IMPORTANT OVERVIEW) These bulbs utilize an advanced LED driving system that allows them to: Maintain full brightness across all colors Prevent dimming when mixing colors Deliver consistent output across the entire system Unlike traditional RGB lighting, where colors lose brightness, this system keeps: Red as bright as white Blue as bright as white Mixed colors at full intensity Why This Matters This results in: Brighter installs Better color quality More consistent lighting across fixtures Fewer lights needed to achieve the same effect Important Note We will go deeper into this technology in a later module focused on landscape lighting and individual bulb performance Universal Compatibility These are standard MR16 bulbs, meaning: They can be used in most standard MR16 fixtures Fixture Quality The sconces used in this system are: Solid brass construction Salt tested for over 500 hours Designed for long - term durability in outdoor environments Finishes Available Black Bronze White Transformer Sizing Transformers available: 75W 150W 300W Power Rule (IMPORTANT) Only use about 85% of transformer capacity Load Calculations Full Sconce (11W each): 75W → ~6 fixtures 150W → ~12 fixtures 300W → ~24 fixtures Half Sconce (5.5W each): 75W → ~12 fixtures 150W → ~24 fixtures 300W → ~48 fixtures Installer Rule Always calculate total wattage before installation

**Module.** Sconce lighting system (LVW)

Lesson 6.3: The 14/2 Waterproof Splice (CRITICAL) Wire Type 14/2G low - voltage burial wire Step 1: Strip Wire Strip outer jacket carefully Expose inner conductors Step 2: Twist Wires Twist fixture wires with main line wires Ensure tight, secure connection Step 3: Waterproof Connection Use one of the following: Waterproof wire nuts Silicone - filled connectors Heat shrink (recommended in tight installations) Heat Shrink Advantage Smaller connection profile Easier to pull through tight spaces (like aluminum enclosures) Strong, sealed waterproof connection Step 4: Seal the Splice Ensure the splice is: Fully sealed Protected from moisture Tight and secure Why This Matters If the splice fails: The light fails The system fails You get a callback Installer Rule A bad splice = a guaranteed service call
